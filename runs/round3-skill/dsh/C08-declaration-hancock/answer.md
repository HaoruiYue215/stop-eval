# 答案

第一处 Massachusetts 与随后的 Maryland 之间的签名是 **John Hancock**（约翰·汉考克）。

## 依据

依据文件：`input/declaration.md`（来源：https://www.archives.gov/founding-docs/declaration-transcript ，抓取日期 2026-11-12）。

该文件签名部分按州排列，第 96 行是第一处州名 `Massachusetts`，第 100 行是 `Maryland`；两者之间只有第 98 行的 `John Hancock` 一个签名。

原文节录（第 94–102 行）：

```
Arthur Middleton

Massachusetts

John Hancock

Maryland

Samuel Chase
```

注：`Massachusetts` 在文件中另有一处（第 182 行，其后为 Samuel Adams、John Adams、Robert Treat Paine、Elbridge Gerry），但题目所指的是**第一处** Massachusetts，故答案为 John Hancock。
